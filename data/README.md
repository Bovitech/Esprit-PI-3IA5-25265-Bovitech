# Datasets

Training data is **not** in Git. To run the app, see the root **[README.md](../README.md)**.

| Data | Used for |
|------|----------|
| IMMU collar CSV | Behavior model (retraining) |
| UWB GPS traces | GPS LSTM |
| Stress sequences | Stress BiLSTM |
| INRAE labels | Illness PPO |
| Skin images | Chatbot EfficientNet |

Only needed if you **retrain** models, not to use the app.
